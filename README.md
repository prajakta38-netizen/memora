# Memora 🎂

Upload a video, get a link, share it with anyone.

## Getting Started

1. Install dependencies: `npm install`
2. Run: `npm run dev`
3. Open: http://localhost:3000

## Features

- Upload videos
- Get shareable links
- Video player
- View counter

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Supabase
